MagicSpot 2.0's first preview is a working Spotify desktop app built from the latest Spotifast foundation, with a redesigned lyrics sidebar and OLED Blue.

**Download for Windows:** extract the Windows x64 ZIP below and open `magicspot2.exe`. Sign in through your browser; local playback requires Spotify Premium. This is the normal app, with real sign-in and playback, rather than the demo.

**Download for macOS:** open the universal DMG below and drag **MagicSpot** into **Applications**. It contains Apple Silicon and Intel builds. This preview is ad-hoc signed but not Apple-notarized; macOS may require approval in **System Settings > Privacy & Security** on first launch.

## New

- **Lyrics with room to breathe.** Larger bold words, a bright active line, a compact song header, smooth following and soft scroll edges. Scroll manually to read elsewhere, use Follow to return, or click a timed line to seek.
- **OLED Blue.** Choose Settings > Appearance > Theme > OLED Blue for black main surfaces and blue accents. The choice is saved between launches.
- **A separate MagicSpot profile.** Settings, caches, credentials, window state and the running-instance channel use MagicSpot 2 identities. Existing Spotifast and MagicSpot v3 profiles are left alone. Sign in afresh.

## Preview details

This first release includes Windows x64 and a universal macOS DMG. It retains upstream Spotify sign-in, local playback and Connect support. Automated tests and native UI captures cover the changes; a live Spotify account playback session has not been exercised here. MilkDrop is omitted from these builds. The Windows executable is unsigned; the Mac app is ad-hoc signed without notarization. Linux remains a source/CI target, without an install package in this release.
