MagicSpot 2.0.1 improves fast-moving lyrics, recovers interrupted playlist loading and refreshes the OLED palette. It also brings in all 23 reviewed Spotifast changes through October 10, 2026.

- **Rapid lyrics stay in step.** Both lyrics views finish scrolling and highlighting before the next rapid line, and the sidebar wakes at lyric timestamps. Saved font, size, glow, cover and background controls remain available.
- **Retry playlist loading.** If a library page fails, loaded playlists stay visible. Retry resumes the failed page instead of clearing the library or silently skipping it.
- **Neutral OLED.** The theme is now named OLED, with white and gray controls on black surfaces. Existing OLED Blue preferences carry over automatically.
- **Upstream playback and library fixes.** Playback recovers when the audio output changes, audio queue waits replace polling, abrupt session exits preserve history and resume position, playlist drags avoid duplicates, album sorting keeps track order, and Blends show contributors. Hidden-window work follows system power/session state more closely.
- **Optional Linux title bar.** Settings > Appearance can enable window controls using the desktop's left/right button layout. It remains off by default. Ukrainian support and Turkish translation improvements are also included.

**Windows x64:** download and open `magicspot2-v2.0.1-x86_64-pc-windows-msvc.exe`. It is a standalone executable with no installer or ZIP. Keep `magicspot2-v2.0.1-THIRD-PARTY-LICENSES.txt` for license notices. The EXE is unsigned and uses the static MSVC runtime.

**macOS, Apple Silicon and Intel:** open `magicspot2-v2.0.1-macos-universal.dmg` and drag MagicSpot into Applications. The app is ad-hoc signed without Apple notarization; first launch may need approval in System Settings > Privacy & Security.

Both downloads contain the normal app, including MilkDrop, without demo data. Sign in through your browser; local playback requires Spotify Premium. Updates remain manual. SHA-256 values are included in `checksums.txt`. Linux and Windows ARM are source/CI targets without downloadable packages in this release.

Publication requires all twelve CI jobs to pass on the exact current-main release commit, verified x64 Windows packaging and a mounted, version/architecture/signature-checked universal DMG. Automated regression tests and matching native demo captures are separate from live Spotify validation. No live account sign-in, playback or Connect session was exercised during this maintenance work.
