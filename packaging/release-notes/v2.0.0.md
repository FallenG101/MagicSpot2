MagicSpot 2.0 is a Spotify desktop app built from the latest Spotifast foundation, with a redesigned lyrics sidebar and OLED Blue.

**Download for Windows:** download and open `magicspot2-v2.0.0-x86_64-pc-windows-msvc.exe`. There is no ZIP to extract and no installer. Sign in through your browser; local playback requires Spotify Premium. This is the normal app with sign-in and playback enabled. Download `magicspot2-v2.0.0-THIRD-PARTY-LICENSES.txt` beside the executable to read the license notices.

**Download for macOS:** open `magicspot2-v2.0.0-macos-universal.dmg` and drag **MagicSpot** into **Applications**. It contains Apple Silicon and Intel builds. The app is ad-hoc signed but not Apple-notarized; macOS may require approval in **System Settings > Privacy & Security** on first launch.

## New

- **Lyrics with room to breathe.** Larger bold words, a subtle glow on the active line, a larger cover/song card, smooth following and soft scroll edges. The sidebar background uses the current song's blurred artwork. Scroll manually to read elsewhere, use Follow to return, or click a timed line to seek.
- **Your lyrics style.** Settings > Appearance offers Inter, System and Monospace fonts, an 18–48 point size slider with Auto mode, plus switches for the glow and artwork background. The cover grows when you widen the sidebar. Turn off the artwork background for a solid theme surface, including pure black in OLED Blue. Choices are saved between launches.
- **OLED Blue.** Choose Settings > Appearance > Theme > OLED Blue for black main surfaces and blue accents. The choice is saved between launches.
- **A separate MagicSpot profile.** Settings, caches, credentials, window state and the running-instance channel use MagicSpot 2 identities. Existing Spotifast and MagicSpot v3 profiles are left alone. Sign in afresh.

## Release details

This release includes Windows x64 and a universal macOS DMG. It retains upstream Spotify sign-in, local playback, Connect and MilkDrop. Automated tests and native UI captures cover the changes; a live Spotify account playback session has not been exercised here. GitHub marks this release Latest on the repository home page. Replacing downloaded apps remains manual. The Windows executable is unsigned; the Mac app is ad-hoc signed without notarization. Linux remains a source/CI target, without an install package in this release.
