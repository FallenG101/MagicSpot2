Lyric timing and playlist recovery

The Library keeps loaded playlists visible when a later page fails. A persistent error and Retry button resume that page. A first-page failure also offers Retry. A loading indicator appears during the request. Navigation, sizing, theme palettes and playlist order retain their existing behavior.

Native Windows demo captures at matching sizes and with matching sample data. Before uses the sidebar rendering from commit 3ddd309, with the new failure fixtures and the same working-tree theme. After uses the updated sidebar. The static lyrics captures check layout; the 120 ms line regression test checks timing in both lyric views. No live Spotify account was used.
