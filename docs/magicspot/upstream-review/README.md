# October upstream interface review

The optional Linux custom title bar in upstream #648 was explicitly approved
by the maintainer on October 10, subject to inspecting native Linux evidence.
It is off by default. Review desktop-configured left/right controls, reserved
space over navigation and side panels, and Appearance settings in light/dark
themes at 1024 × 768 and 1280 × 800.

[Combined comparison](index.html) provides platform, PR/state, theme and size
selectors, Previous/Next, Before/After and individual comparison links.
[Windows comparison](windows/index.html) contains matching playlist and radio
captures from the preserved local improvements (`8491cf3`) and 2.0.1 source
(`500db5f`). All sixteen captures were inspected, including full-size light
narrow radio and dark normal playlist views. Artwork, labels and controls fit;
no Windows layout regression was seen. The exact capture metadata is stored
beside each comparison. Native captures settle for five seconds with isolated
demo profiles and identical inputs.

[Linux comparison](linux/index.html) contains 56 matching captures generated by
[CI 38085687912](https://github.com/FallenG101/MagicSpot2/actions/runs/38085687912)
on `97d955fc168a4f05504b834e9eec954264deb572`. All seven cases were inspected
in light/dark themes at both sizes, with full-size inspection of the default
lyrics view, left/right controls, settings and Blend contributors. Default-off
layout is retained. Enabled buttons leave clear space above navigation, lyrics
and queue. The setting and playlist labels fit; no adjustment is required.
[Review metadata](linux/REVIEW.json) binds this inspection to the application
source tree. After inspection the maintainer removed Linux builds and review
from publication gates; this evidence remains a historical record. This is
native rendering under Xvfb, not an interactive test of a
physical Linux desktop. Static
captures check layout; regression tests cover loading transport buttons,
shuffle hover, contributor lookup, song-radio naming and held slider presses.
No live Spotify account is used for these captures or tests.

Linux capture builds run under Xvfb with a private D-Bus session and isolated
GNOME button-layout settings. An identical `review-blend` fixture is applied
only to two throwaway source checkouts, so #745 can be compared with the same
Spotify-owned playlist and contributors on both sides. The product UI is
unchanged by that fixture. Its source is in
`.github/scripts/install-review-fixtures.py`; it is not part of ordinary builds.
Both throwaway builds also use the real Settings search for “Custom title bar”
instead of the full Appearance group, keeping its switch visible at both sizes.
